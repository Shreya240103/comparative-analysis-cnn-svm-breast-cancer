# Breast Cancer Detection using CNN vs SVM

## 📌 Overview
This project presents a comparative study of Convolutional Neural Networks (CNN) and Support Vector Machines (SVM) for the detection of breast cancer using AI and machine learning techniques.

## 🧠 Models Used
- Convolutional Neural Network (CNN)
- Support Vector Machine (SVM)

## 📊 Evaluation Metrics
The performance of both models was evaluated using:
- Accuracy
- Precision
- Recall
- F1-Score
- ROC Curve

## 📈 Results
Both models were compared based on their performance metrics. The ROC curve was used to visualize classification performance and compare the effectiveness of CNN and SVM.

## 📁 Files Included
- `breast_cancer_analysis.ipynb` → Complete implementation and analysis

## 🚀 Technologies Used
- Python
- TensorFlow / Keras
- Scikit-learn
- NumPy, Pandas
- Matplotlib

## 🎯 Objective
To compare machine learning and deep learning approaches for early detection of breast cancer and evaluate their performance in a healthcare context.
